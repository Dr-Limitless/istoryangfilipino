# Storyang Filipino — preserve the existing UI

The user explicitly requested the original website UI on 2026-09-15 and rejected the replacement serif/editorial layout. Future work must enhance the incumbent identity rather than redesign it.

Preserve Inter typography, bold white/blue Storyang Filipino lettering, dark surfaces, full-background cover videos, and the existing rounded story cards and progress presentation. Retain the brand logo and three cover clips. Limit enhancements to useful navigation, mobile spacing, accessible focus, readability and purposeful state feedback. Do not reintroduce Source Serif typography or a split-panel homepage hero.

The Gabay is an animated manual, not a separate reading page. It opens on a browser's first visit, allows skipping, and can be reopened from the navigation, hero help button or footer. Five chapters introduce story selection, ten vocabulary matches, ten hidden words, reflection and progress. Page-turn movement communicates chapter changes, with no spatial motion under reduced-motion preferences. Matching, word selection and reflection practice stay inside the manual and never affect real activity scores or send results.

The manual uses the site's existing dark/blue palette. Desktop has a chapter index beside the active page; mobile has compact numbered navigation above the page. Native dialog behavior traps focus and makes the background inert; Escape and Laktawan close it. Completion remembers the visit on this browser, while /gabay remains a direct link to the manual.

Client-provided activity additions and the reflection rubric belong inside the existing “Mga Aktibidad” flow. The shared leaderboard is active through Firebase.
